# Pizza z Pieca — AI Kelner MVP

Aplikacja przygotowana dla Pizza z Pieca, Dworcowa 4, Katowice.

## MVP
- stolik do 20+ osób
- wybór osoby przy zamówieniu
- speech-to-text w przeglądarce (pl-PL)
- zamówienia przypisane do osób
- budowanie rachunku z zamówienia
- przypisanie pozycji do osób
- pozycje wspólne i automatyczny podział
- indywidualne linki/QR-ready dla każdego gościa
- localStorage + PWA shell

## Następny etap
Speaker diarization, OCR paragonu, Supabase, płatności i integracja POS.

Projekt korzysta z prostych, dobrze znanych wzorców open-source (bill splitting, Web Speech API/PWA), ale kod MVP jest ułożony pod Pizza z Pieca zamiast kopiowania nieznanego kodu/licencji 1:1.
